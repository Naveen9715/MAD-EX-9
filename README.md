# 📄 Dynamic JSON Employee Card Parser (MAD Exercise 9)

An Android application demonstrating programmatic JSON payload parsing and dynamic view rendering inside a scrollable layout.

## 📱 Features

- **JSON Parsing**: Parses nested JSON objects and arrays using native org.json.JSONObject and org.json.JSONArray.
- **Dynamic View Inflation**: Programmatically creates and styles custom TextView components at runtime without static layout constraints.
- **Scrollable Card Layout**: Embedded inside a responsive ScrollView and LinearLayout for smooth scrolling of data entries.
- **Custom View Styling**: Dynamically applies padding, bold typefaces, text sizing, and visual divider separators between records.

## 🛠️ Built With

- **Language**: Java
- **Platform**: Android
- **JSON Engine**: org.json
- **UI Architecture**: Programmatic UI rendering with ScrollView & LinearLayout
